## v1 实机反馈与修正方向

用户反馈两档均为不透明文字，且出现锯齿。复查确认：一般字形 DrawPath 不消费
PassBlur / BloomStroke 属性；原 DrawText 的文字抗锯齿也不能靠复制 DlPaint 自动
继承到路径。v1 的主机用例只证明调用/恢复/所有权，**不能证明材质被消费**。
原测试包保留，不覆盖其文件或历史提交。

当前版本保留三档选择，但只继续试验模糊；柔光玻璃明确标注尚未接通并保留系统文字，
不再通过无效的 BloomStroke 参数冒充 MiGlass。模糊指字形内部的背景模糊采样。

| 选项 | 当前代码行为 | 验证边界 |
| --- | --- | --- |
| 默认 | 系统原绘制，首次默认状态不安装新绘制 Hook | 主机回归 |
| 模糊 | 原排版字形 → AA ClipPath → 原生 PassBlur DrawRect → 高斯纹理采样 | 尚待新包真机验证背景纹理、洞口和观感 |
| 柔光玻璃 | 暂时保留系统原绘制，设置页/配置日志标明未接通 | 字形 MiGlass 尚未实现 |

## 生命周期与性能

仅匹配原元素名 `center_classic_plus`，保留字体、字体轴、格式、位置和点击语义；
日期/天气保持原样。不缓存 Dart、View、Context 或字形对象；使用同一引擎构造与析构。
设置在下次原生时钟重绘时生效，可能要等下一分钟；不强制刷新或增设时钟定时器。
非 Impeller、非填充/实色画笔、已有滤镜/材质和半透明动画直接走原文字绘制。

没有新增进程作用域、截图、覆盖窗口或轮询。首次默认/玻璃未接通状态不安装绘制 Hook。
开启模糊后，非目标段落只查 TLS，非目标矩形只查专用标记；元数据和安装仍在原工作线程。
背景源诊断按首次见到的状态去重，每个进程至多 3 次 eventfd 唤醒，由工作线程写日志；
不逐帧打印、不在回放线程写文件或做同步 IPC。

新增成本包括：目标重绘的原生字形提取与路径分配、AA 裁剪，以及真实背景高斯模糊和半透明混合的
GPU 成本。缓存 id 为固定专用键（同进程/上下文复用），不使用随机/递增键；
原生缓存按 id/namespace 查找，半径变化会替换槽，因此不能占用系统默认 id 100，
以免不同半径互相驱逐。原生窗口纹理可能为全窗口，不能因时钟面积小就宣称模糊开销小；缓存复用
也不是性能测量结果。尚未测新版本帧率、卡顿率或耗电。
