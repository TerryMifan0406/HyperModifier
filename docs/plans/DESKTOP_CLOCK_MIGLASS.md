目标是原时钟数字的玻璃材质：保持原生时间格式、前导零规则、字体/原生字体轴、
点击语义、日期与天气。验证范围先限定默认经典 4×2 的主时间；双时钟、主题替换
和任意资源通配支持留待实际接口成立后扩展。动态实例 id 只用于日志，不作永久规则。

## 原型约束与回归

复用 MAML/Flutter 原图形管线；不新增 SystemUI 进程 Hook、桌面覆盖窗口、常驻
定时器、逐帧截图或 CPU 像素扫描。原 frameRate=0 / DateTime.Minute 仍是基线。
背景材质是否依赖持续刷新要单独核对，不能为了看见效果就强制 60/120fps。

热路径只做廉价能力/目标判断；在加载或相关属性变更时更新资源、规则与元数据。
不能缓存裸 Dart 堆对象跨 GC；Rust Rc、FFI 字符串及 Flutter shared_ptr 的所有权
需按实际调用核对，不通过改未知 Option/枚举布局强行开启。

功能验收包括：0/6/8/9 的洞口、冒号、12/24 小时、午夜/跨分钟、前导零开关、
字体/轴/粗细变更、亮暗壁纸、滑页/解锁、编辑/移动/删除/重加、全局材质关闭、
实时开关恢复、多实例与其他 MAML 不受影响。范围扩大前另测双时钟和主题资源更新。

性能先审查分配、反射、IPC、锁、缓存失效与 GPU pass；运行时原型成立后，以同
设备/刷新率/温度/设置/操作做 Perfetto、FrameTimeline、CPU/分配采样。未取得
对照数据前不声称帧率、卡顿率或功耗改善。

手机操作继续遵守只读约束；安装验证需另行获得授权，不能自动安装或重启。
