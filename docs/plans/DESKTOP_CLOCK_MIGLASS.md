## v1 实机反馈与修正方向

用户反馈两档均为不透明文字，且出现锯齿。复查确认：一般字形 DrawPath 不消费
PassBlur / BloomStroke 属性；原 DrawText 的文字抗锯齿也不能靠复制 DlPaint 自动
继承到路径。v1 的主机用例只证明调用/恢复/所有权，**不能证明材质被消费**。
原测试包保留，不覆盖其文件或历史提交。

当前版本保留三档选择，但只继续试验模糊；柔光玻璃明确标注尚未接通并保留系统文字，
不再通过无效的 BloomStroke 参数冒充 MiGlass。模糊指字形内部的背景模糊采样。

| 选项 | 当前代码行为 | 验证边界 |
| --- | --- | --- |
| 默认 | 系统原绘制，首次默认状态不安装新绘制 Hook | 主机回归 |
| 模糊 | 原文字 atlas alpha → 有界 SaveLayer → PassBlur DrawRect / SrcIn → 原生合成 | v2 模糊已由用户确认；v3 边缘与明暗待真机验收 |
| 柔光玻璃 | 暂时保留系统原绘制，设置页/配置日志标明未接通 | 字形 MiGlass 尚未实现 |

## 生命周期与性能

仅匹配原元素名 `center_classic_plus`，保留字体、字体轴、格式、位置和点击语义；
日期/天气保持原样。不缓存 Dart、View、Context 或字形对象；借用画笔/向量视图仅在同步调用内有效，不对外来对象运行析构。
设置在下次原生时钟重绘时生效，可能要等下一分钟；不强制刷新或增设时钟定时器。
非 Impeller、非填充/实色画笔、已有滤镜/材质和半透明动画直接走原文字绘制。

没有新增进程作用域、截图、覆盖窗口或轮询。首次默认/玻璃未接通状态不安装绘制 Hook。
开启模糊后，非目标段落只查 TLS，非目标矩形只查专用标记；元数据和安装仍在原工作线程。
背景源诊断按首次见到的状态去重，每个进程至多 3 次 eventfd 唤醒，由工作线程写日志；
不逐帧打印、不在回放线程写文件或做同步 IPC。

v3 移除了目标重绘中的字形路径提取、包装和析构，继续使用系统文字 atlas。新增一个仅覆盖
blob bounds（含 1 个局部坐标单位外扩）的 GPU 离屏层；仍有真实背景高斯模糊和半透明混合的
GPU 成本。没有 CPU 截图或自建常驻遮罩缓存；不能据此推断整体 GPU 成本更低。缓存 id 为固定专用键（同进程/上下文复用），不使用随机/递增键；
原生缓存按 id/namespace 查找，半径变化会替换槽，因此不能占用系统默认 id 100，
以免不同半径互相驱逐。原生窗口纹理可能为全窗口，不能因时钟面积小就宣称模糊开销小；缓存复用
也不是性能测量结果。尚未测新版本帧率、卡顿率或耗电。

### v3 实现与验收边界（2026-10-22）

用户确认 v2 的背景模糊已生效，当前反馈是“偏暗、数字不够清晰”和锯齿。
不能把 ClipPath 的 AA 请求视为最终字形边缘质量保证。v3 改为：

1. 原生 ParagraphPainter 使用白色、保留原排版和字体的借用画笔，绘制到有界透明层。
2. 引擎 PassBlur 矩形以 SrcIn（枚举值 5）乘以原文字 alpha；保留洞口与 atlas 分数覆盖。
3. restore 合成，并显式恢复 DisplayList AA、原文字颜色/混合模式及先前材质。

参数默认半径 12 px、文字显色强度 36%（v2 为 20%）；范围分别 2..40、0..80。
显色跟随原字体颜色，浅色字体提高强度会提高明亮度；不是固定白色盖层或自动对比度算法。
参数打包为一个 i32，经既有 SystemUI carrier 发送，滑块沿用停稳/松手后提交策略。
原生仅在参数变化时写独立四字节缓存；绘制只读一个原子快照，无新增 IPC/轮询。
缺少可选 Bundle_get_i32 的旧接口不影响现有布尔设置和功能安装。

首次升级涉及 SystemUI 桥接代码，需用户手动重启系统界面和桌面（或重启手机）。
后续改参数等原时钟下一次重绘，可能到下一分钟。本轮不自动安装、不操作手机。
新遮罩效果、滑页/解锁等动画、GPU 层成本和耗电尚未实测；柔光玻璃仍未接通。
